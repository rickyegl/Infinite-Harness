# game.roblox.combat

The Combat part of the Roblox game, hidden from the router. It switches on server-side swings (reach, cooldown, slow, shove, hit feed); draws the reach.

The runner is shared by all six parts: `../game.roblox/lib/parts.ts`. Mock: `fixtures/default.jsonl`,
recorded with `pnpm fixture <runId> <nodeId> game.roblox.combat`.
