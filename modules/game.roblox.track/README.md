# game.roblox.track

The Track part of the Roblox game, hidden from the router. It lays the road parts on the same centre line as the Unity game (exported by the Unity editor) and draws it from above and in profile.

The runner is shared by all six parts: `../game.roblox/lib/parts.ts`. Mock: `fixtures/default.jsonl`,
recorded with `pnpm fixture <runId> <nodeId> game.roblox.track`.
