# game.roblox.karts

The Karts part of the Roblox game, hidden from the router. It writes the karts section: part-built karts that drive in track space, players plus AI; draws the grid.

The runner is shared by all six parts: `../game.roblox/lib/parts.ts`. Mock: `fixtures/default.jsonl`,
recorded with `pnpm fixture <runId> <nodeId> game.roblox.karts`.
